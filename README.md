# PricePulse

Интерактивный прототип Telegram Mini App для мониторинга цен.

## Что уже работает

- каталог товаров и фильтрация по категориям;
- избранное и поиск;
- добавление товара по ссылке;
- интервалы мониторинга от 1 часа и собственный период;
- целевая цена для уведомления;
- карточка товара с историей цены;
- локальное сохранение пользовательских товаров;
- адаптация под мобильный Telegram WebView и тактильный отклик Telegram.

## Следующий этап

Для реального фонового мониторинга нужен серверный слой: парсер LIS-SKINS, база пользователей и товаров, очередь периодических проверок и Telegram-бот для уведомлений. Текущий интерфейс уже подготовлен под эти сценарии.

## Запуск

```bash
npm install
npm run dev
```

Проверка сборки: `npm test`.
